# Agent Context Folder

This folder is for AI agents (me and any future agents) working on this codebase. It explains what the user wants, what currently exists, and what still needs to be done.

- `vision.md` — what the user wants the system to become
- `current-state.md` — what the existing code does right now
- `todo.md` — the remaining work

Keep this folder up to date when making changes so the next agent can pick up context quickly.
